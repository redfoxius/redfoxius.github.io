# redfoxius.github.io

Portfolio site: case studies of projects by Oleksandr Kolomoiets. Built with Astro, deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

- Case studies: `src/content/projects/*.md` (front matter: title, summary, group, status, stack, links, order)
- Local preview: `npm install && npm run dev`
